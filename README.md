# Academic Command Center PWA

Fresh-start PWA version. Streak starts at 0; completing at least one planned task in a day makes that day active. College progress is 0% until subjects have actual progress.

For installation, serve this folder over HTTPS (or localhost for testing). Opening index.html directly as file:// will not enable service-worker installation.

Note: this PWA keeps the current app's local data on each device. Cross-device syncing requires a cloud backend/database in a later phase.
